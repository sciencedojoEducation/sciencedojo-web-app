# Academy learning-journey characters

Four original illustrations generated using the built-in image generation tool with the imagegen skill. These are decorative, not instructional images or completion indicators.

Files: `learn-v1.webp`, `try-v1.webp`, `use-v1.webp`, `review-v1.webp`.

Generated with transparent backgrounds; resized to 384 pixels high and encoded as WebP with alpha preserved. The UI uses `object-contain`, empty alternative text and `aria-hidden`, so it does not crop people or repeat the adjacent stage labels to screen readers.
