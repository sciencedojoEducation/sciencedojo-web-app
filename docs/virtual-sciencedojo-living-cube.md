# Living Cube — authorized private-beta plan, 19 October 2026

The owner requested richer movement, solid furniture, room glass controls and a
cozy, natural, science-oriented school with accessible upper floors. This request
authorizes the following software iteration. Existing courses, dashboards and
admission/release gates remain in force.

1. Add Shift running, Space jumping, C crouching and Z lying prone, with visible
   alternatives. Authority owns speeds, bounded jumps, posture and input expiry.
   Furniture shares its actual procedural geometry with collision/wayfinding;
   jumping does not bypass solid furniture or walls.
2. Give every enclosed room a focus-glass switch. Nearby E or the room button
   changes shared opaque glazing. This is visual screening, not access control:
   doors remain open and campus presence stays shared. No private chat is added.
3. Make three usable levels: existing ground school, a learning/science level
   and a wellbeing/discovery level. Add furnished classrooms, study stations,
   beanbags, plants and fitness spaces. A lift provides accessible travel;
   escalators and a slide provide animated, server-owned journeys. Floor edges
   remain bounded. Course computers reuse the retained authorized Study Hub;
   actual live teaching is not introduced by decorating a classroom.
4. Extend both authorities, strict public geometry contracts and local-only SQL
   migration together. Keep transport internals/timestamps out of snapshots,
   prevent remote switches/floor/position claims, and clear expired travel/input.
5. Check movement/obstacle parity, floor and seat isolation, shared switching,
   transport interruption/recovery, keyboard/course isolation and real rendered
   poses/floors. Retain the existing continuity and draw-call limits. Update the
   runbook and repository instructions with actual results before completion.

Implementation is for local private review. No hosted schema application, paid
infrastructure, lesson entitlement or real-learner admission is authorized here.

Software implementation and local verification are complete for private review;
see the [runbook](virtual-sciencedojo-implementation.md). Three usable levels,
27 places and 20 workstations are implemented. Human acceptance and all hosted
schema/operational gates remain separately pending.
