# The Cube — private beta design

A transparent scientific school set inside a literal glass cube: learning pavilions, trees and water at ground level, an illuminated orbital sculpture in the tall atrium, and a landscape visible through the envelope. Metal mullions and luminous edges make the cubic shape legible at night. The fifteen existing destinations remain the accessible ground campus; upper framing is architecture, not new teaching floors.

The owner authorized this iteration on 18 October 2026. Work covers the local visual/camera/environment software only. Existing account/course systems, privacy controls and operational release gates remain in force.

Implementation sequence: shared camera/sky math and accessible controls; instanced glass architecture/landscape and celestial environment; browser/render/recovery verification and refreshed synthetic preview. Local 24-hour time is the default, with manual sunrise/day/sunset/night previews. Time/camera state is never added to multiplayer messages.

Implemented in the private beta: a literal 144-unit cubic envelope, planted perimeter terraces, suspended orbital sculpture, glass learning pavilions, forests/hills/water, exterior/aerial/follow/orbit/first-person cameras, local 24-hour/manual sky controls, sun, moon and a deterministic star field. Ground destinations remain the 15 existing places and 10 authorized-course study stations. Upper terraces are architectural scenery; vertical circulation/new accessible floors are not implemented.

Camera-relative first-person inputs are normalized to the existing server protocol's bounds; camera angles, clock/timezone and sky preferences are never added to shared state. First person uses confirmed-pose eye height 1.67 (1.25 seated), hides the self avatar and uses a 70-degree field of view. Drag/touch look, Q/E turning, accessible look/zoom buttons and manual/live clock controls remain local. Aerial cutaway exposes the existing ground map. This is a stylized visual 24-hour cycle, not a geolocated astronomical model.

Local verification passed 492 tests, type/scoped lint, both maintained browser transports (including first-person rotated movement, clock keyboard/live controls and existing course/privacy/recovery checks), normal/reduced-motion/stressed actual-scene probes, production build and workbook traces. The render probe also checks Cube visibility/cutaway, day/night sun/moon/stars and actual eye-level projection. Current hosted results are tracked separately in draft PR 17; no current-head hosted pass is inferred from local commands. No hosted schema, paid service or learner launch is included.

Visual review also keeps the aerial plan clear by hiding elevated terrace planting with the Cube cutaway. First-person mode removes floating place labels, retaining the ground-location caption and accessible map; camera matrices update before marker projection in other views. Final local normal/reduced-motion probes passed after these adjustments.

Slow-device review found that disabling the renderer's shadow pipeline can compile new shader variants during movement. The fallback now changes the existing `receiveShadow` uniform on school props while retaining the cached shadow pipeline and map. This removes decorative shadow sampling alongside the single DPR reduction without a shader-definition change. The actual-scene probe observes receiving meshes and pipeline stability; movement/draw-call thresholds and the confirmed-pose buffer are unchanged.
